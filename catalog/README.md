# Catalog

Machine-readable indexes and generated documentation for RE-Skills.

## Files

| File | Format | Description |
|------|--------|-------------|
| `skills-index.yaml` | YAML | All 44 skills with name, description, type, path, intent |
| `skills-by-type.md` | Markdown | Skills grouped by type (Component, Interactive, Workflow) |
| `commands-index.yaml` | YAML | All 9 commands with name, description, uses, outputs |
| `commands.md` | Markdown | Command descriptions with skill chains and outputs |

## Usage

**For agents:** Read `skills-index.yaml` or `commands-index.yaml` to programmatically discover skills and commands.

**For humans:** Read `skills-by-type.md` or `commands.md` for browsable catalogs. Or use `LIST.md` in the repo root.
