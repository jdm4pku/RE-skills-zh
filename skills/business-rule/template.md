# 业务规则模板

使用此模板记录各条业务规则。

## 模板

```markdown
# 业务规则目录：[项目名称]

**版本：** [x.y]
**日期：** [YYYY-MM-DD]
**作者：** [姓名]

---

## 业务规则：[BR-ID]

- **规则名称：** [简短的描述性名称]
- **类型：** [事实 / 约束 / 动作使能 / 推断 / 计算]
- **声明：** [用精确、无歧义的自然语言描述的规则]
- **来源：** [该规则的出处 -- 政策文件、法规、主题专家姓名]
- **理由：** [该规则存在的原因]
- **相关需求：** [实现该规则的 FR-ID]
- **相关用例：** [引用该规则的 UC-ID]
- **易变性：** [稳定 / 每年 / 频繁]
- **生效日期：** [该规则生效或已生效的时间]
- **上次审查：** [上次与来源验证的日期]

*（对每条业务规则重复以上内容）*

---

## 规则冲突矩阵

| 规则 A | 规则 B | 冲突 | 解决方案 |
|--------|--------|------|----------|
| [BR-ID] | [BR-ID] | [描述] | [哪个规则优先以及原因] |
```

## 注意事项
- 每条规则都需要来源。"大家都知道"不是有效来源。
- 按类型分类以使目录可导航（按约束、计算等筛选）。
- 对高易变性规则至少每季度审查一次。
- 当规则变更时，先更新规则，然后追溯到受影响的需求。
