# 对话图示例

## 示例：ChemTrack 对话图

```markdown
# 对话图：ChemTrack 化学品库存管理系统

**版本：** 1.0
**日期：** 2025-04-01

---

## 界面清单

| 界面 ID | 界面名称 | 用途 | 用例 | 访问角色 |
|---------|----------|------|------|----------|
| SCR-01 | Login（登录） | 验证用户身份 | -- | 全部 |
| SCR-02 | Dashboard（仪表盘） | 汇总统计、导航中心 | UC-1 | 所有已认证用户 |
| SCR-03 | Chemical Search（化学品搜索） | 搜索和筛选化学品 | UC-4 | 技术员、EHS 专员 |
| SCR-04 | Chemical Detail（化学品详情） | 显示单个化学品的完整信息 | UC-4 | 技术员、EHS 专员 |
| SCR-05 | Add Chemical Form（添加化学品表单） | 录入新化学品数据 | UC-3 | 技术员 |
| SCR-06 | Edit Chemical Form（编辑化学品表单） | 修改现有化学品信息 | UC-6 | 技术员 |
| SCR-07 | Confirmation（确认） | 操作后的成功消息 | UC-3, UC-6 | 技术员 |
| SCR-08 | Dispose Chemical（处置化学品） | 记录处置信息 | UC-9 | 技术员 |
| SCR-09 | Alert Dashboard（告警仪表盘） | 查看过期告警 | UC-5 | 技术员、EHS 专员 |
| SCR-10 | Report Generator（报告生成器） | 配置并运行报告 | UC-7, UC-8 | EHS 专员 |

---

## 导航路径

### 来源：Login（SCR-01）

| # | 触发器 | 守卫条件 | 目标 | 动作 |
|---|--------|----------|------|------|
| 1 | 提交凭证 | 有效 | Dashboard（SCR-02） | 创建会话 |
| 2 | 提交凭证 | 无效 | Login（SCR-01） | 显示错误，增加尝试次数 |
| 3 | 第 5 次失败尝试 | 尝试次数 >= 5 | Login（SCR-01） | 锁定账户 30 分钟 |

### 来源：Dashboard（SCR-02）

| # | 触发器 | 守卫条件 | 目标 | 动作 |
|---|--------|----------|------|------|
| 1 | 点击"搜索" | 无 | Chemical Search（SCR-03） | 无 |
| 2 | 点击"添加化学品" | 角色=技术员 | Add Chemical（SCR-05） | 初始化表单 |
| 3 | 点击"告警" | 角色=技术员/EHS | Alert Dashboard（SCR-09） | 加载告警 |
| 4 | 点击"登出" | 无 | Login（SCR-01） | 销毁会话 |
| 5 | 会话超时（30 分钟） | 不活跃 | Login（SCR-01） | 保存草稿，销毁会话 |

### 来源：Add Chemical Form（SCR-05）

| # | 触发器 | 守卫条件 | 目标 | 动作 |
|---|--------|----------|------|------|
| 1 | 点击"保存" | 数据有效 | Confirmation（SCR-07） | 验证 CAS 编号，保存记录 |
| 2 | 点击"保存" | 数据无效 | Add Chemical（SCR-05） | 显示字段错误 |
| 3 | 点击"取消" | 无 | Dashboard（SCR-02） | 如已修改则确认丢弃 |

---

## 对话图图示（文本表示）

```
[Start] --> (SCR-01: Login)
  --有效--> (SCR-02: Dashboard)
  --无效--> (SCR-01) + 错误

(SCR-02: Dashboard)
  --"搜索"--> (SCR-03: Chemical Search)
  --"添加化学品" [技术员]--> (SCR-05: Add Chemical Form)
  --"告警"--> (SCR-09: Alert Dashboard)

(SCR-03) --选择--> (SCR-04: Detail) --"编辑"--> (SCR-06) --保存--> (SCR-07)
(SCR-05) --保存有效--> (SCR-07: Confirmation) --确定--> (SCR-02)
```

---

## 用例到界面映射

| 用例 | 步骤 | 界面 | 用户操作 |
|------|------|------|----------|
| UC-3 | 1. 选择"添加化学品" | SCR-02 | 点击按钮 |
| UC-3 | 2. 输入数据 | SCR-05 | 填写字段 |
| UC-3 | 3. 提交 | SCR-05 | 点击"保存" |
| UC-3 | 4. 确认 | SCR-07 | 查看成功消息 |
| UC-4 | 1. 导航到搜索 | SCR-02 | 点击"搜索" |
| UC-4 | 2. 输入条件 | SCR-03 | 输入并筛选 |
| UC-4 | 3. 选择结果 | SCR-03 | 点击行 |
| UC-4 | 4. 查看详情 | SCR-04 | 查看记录 |
```

**为什么有效：**
- 每个界面都有唯一 ID、明确用途和用例关联
- 导航路径包含正常路径、错误路径、取消和超时
- 基于角色的访问作为守卫条件指定
- 返回导航和取消行为被明确定义
- 用例映射确保没有步骤缺少对应的界面
