# 数据建模（ERD）模板

使用此模板在概念级别记录实体-关系图。

## 模板

```markdown
# 实体-关系图：[项目名称]

**版本：** [x.y]
**日期：** [YYYY-MM-DD]
**表示法：** [Chen / 鸦爪（Crow's Foot）]

---

## 实体

### [实体名称]
- **描述：** [该实体代表什么]
- **主键：** [唯一标识符]
- **属性：**
  | 属性 | 类型 | 是否必需？ | 描述 |
  |-----------|------|-----------|-------------|
  | [名称] | [类型] | 是/否 | [含义] |

*（对每个实体重复上述内容）*

---

## 关系

### [实体 A] -- [实体 B]
- **动词短语：** [实体 A] [动词] [实体 B]
- **基数：** [1:1 / 1:N / M:N]
- **A 的参与性：** [强制/可选]（最小值：[0/1]，最大值：[1/N]）
- **B 的参与性：** [强制/可选]（最小值：[0/1]，最大值：[1/N]）
- **关联实体（如为 M:N）：** [名称，如适用]

*（对每个关系重复上述内容）*

---

## 弱实体

### [弱实体名称]
- **依赖于：** [所属实体]
- **部分键：** [所属实体内的标识属性]
- **删除规则：** [级联删除 / 限制删除]

---

## ERD 图（文本形式）

```
[实体 A] ||--o{ [实体 B] : "[动词]"
```

## 验证检查清单

- [ ] 每个实体都有主键
- [ ] 每个关系在两端都有基数和参与性
- [ ] M:N 关系已通过关联实体解析
- [ ] 没有孤立实体
- [ ] ERD 与数据字典一致
```

## 注意事项
- 这是概念模型，而非物理数据库模式。
- 请交叉参考数据字典以获取详细的属性定义。
