# 需求获取研讨会示例

## 示例：ChemTrack 发现研讨会计划

```markdown
# 获取会议计划：ChemTrack 初始发现

**日期：** 2025-03-25
**引导者：** Sarah Chen，业务分析师
**记录员：** James Wong，初级业务分析师
**时长：** 3小时（09:00 - 12:00）
**地点：** 化学楼，204会议室

---

## 目标
在本次会议结束时，我们将识别出化学品库存管理的所有主要用户
工作流程、当前基于电子表格流程的关键痛点，以及排名前3的
功能的初始需求。

## 参与者

| 姓名 | 角色 | 视角 |
|------|------|------|
| Maria Santos | 实验室技术员 | 日常化学品管理 |
| Dr. James Lee | 实验室主任 | 监督与审批 |
| Tom Rivera | 环境健康安全官员 | 法规合规 |
| Kim Park | 实验室技术员 | 化学系工作流程 |
| Sarah Chen | 业务分析师/引导者 | 需求获取 |
| James Wong | 初级业务分析师/记录员 | 文档记录 |

## 已完成的准备工作
- [x] 审阅了现有化学品跟踪电子表格（3个模板）
- [x] 阅读了EPA法规报告要求（40 CFR 260-270）
- [x] 与Tom Rivera进行了非正式访谈（30分钟电话）
- [x] 准备了议程和问题清单
- [x] 打印了当前工作流程图供标注
- [x] 准备了便利贴、马克笔、白板

---

## 议程

### 09:00-09:15 欢迎与基本规则（15分钟）
- 自我介绍和角色说明
- 基本规则：没有坏点子、一次一人发言、手机静音
- 将目标声明写在白板上
- 录音许可（音频）-- 签署同意书

### 09:15-09:45 背景介绍（30分钟）
**活动：** 现状走查
- Maria走查化学品管理的典型一天
- Tom描述季度合规报告流程
- Dr. Lee描述审批和监督流程
- 在白板上记录：泳道图

**关键问题：**
- "请带我走一遍接收新化学品的流程。"
- "您目前如何跟踪哪些化学品即将过期？"
- "当您需要在实验室找到某种特定化学品时会发生什么？"
- "请带我走一遍生成季度EPA报告的流程。"

### 09:45-10:30 痛点获取（45分钟）
**活动：** 便利贴头脑风暴 + 亲和分组
1. 每位参与者在便利贴上写下痛点（5分钟，安静）
2. 贴在白板上并大声朗读（10分钟）
3. 将相似的痛点归类为主题（10分钟）
4. 讨论每个主题：严重程度、频率、影响（20分钟）

**每个主题的追问：**
- "这种情况多久发生一次？"
- "发生时会有什么后果？"
- "您今天是如何应对的？"

### 10:30-10:45 休息（15分钟）

### 10:45-11:30 需求头脑风暴（45分钟）
**活动：** "什么能让您的工作更轻松？"
1. 针对每个痛点主题，头脑风暴解决方案（便利贴，10分钟）
2. 按功能领域分组（10分钟）
3. 讨论可行性和优先级（25分钟）
   - 投点法：每位参与者获得5个点贴在优先事项上

**问题：**
- "如果您可以改变一件事，会是什么？"
- "系统需要做哪些电子表格无法做到的事情？"
- "什么会让您确信化学品数据是准确的？"

### 11:30-11:50 优先级排序（20分钟）
**活动：** 快速MoSCoW
- 将投票后的功能归入第1版的Must/Should/Could/Won't类别
- 记录Must-Have项目的理由

### 11:50-12:00 总结（10分钟）
- 回顾行动项
- 确认后续会议（与Maria、Tom的个别访谈）
- 感谢参与者
- 时间线：需求草案在一周内发送供评审

---

## 会后产出（24小时内完成）

### 已识别的痛点（按主题分组）

**主题1：过期化学品（12张便利贴）**
- 化学品过期而无人注意
- 季度审计发现10-15%的库存已过期
- 2025年2月发生了使用过期试剂的安全未遂事件
- 没有自动提醒或警报

**主题2：报告负担（8张便利贴）**
- EPA报告需要2-3天的手动数据汇编
- 数据分散在6个不同的电子表格中
- 每年格式变化需要重新制作模板
- 无法快速验证数据准确性

**主题3：搜索与定位（6张便利贴）**
- 寻找特定化学品需要在实验室里走一圈
- 没有按CAS号码进行的集中查询
- 化学品有时被移动但未更新电子表格
- 新员工不了解"系统"（非正式知识）

### 需求草案（初始）
[使用 skills/user-story-re 模板以用户故事形式获取]
- 已识别8个Must-Have故事
- 5个Should-Have故事
- 4个Could-Have故事
- 3个推迟到未来版本


### 后续行动
1. 与Maria的个别访谈（化学品入库工作流程细节）
2. 与Tom的个别访谈（合规报告需求）
3. 观察Kim进行实际化学品库存更新（2小时）
4. 文档分析：审阅EPA表格8700-12及州级等效表格
```

**为什么这样有效：**
- 会议前有明确的目标、参与者和议程
- 在一次会议中使用多种技术（走查、头脑风暴、优先级排序）
- 引导注释包含追问问题（不仅仅是"讨论"）
- 会后文档是结构化且可操作的
- 后续行动确保需求获取在研讨会之后继续进行
