# 判定表示例

## 示例 1：化学品处置授权

```markdown
# 判定表：化学品处置授权

**来源：** BR-019（处置审批规则）、BR-020（危险品文档）

---

## 条件和动作

| | 规则 1 | 规则 2 | 规则 3 | 规则 4 | 规则 5 | 规则 6 | 规则 7 | 规则 8 |
|---|--------|--------|--------|--------|--------|--------|--------|--------|
| **条件** | | | | | | | | |
| 化学品是否危险？ | Y | Y | Y | Y | N | N | N | N |
| 数量 > 5 kg？ | Y | Y | N | N | Y | Y | N | N |
| 化学品是否过期？ | Y | N | Y | N | Y | N | Y | N |
| **动作** | | | | | | | | |
| 需要 EHS 官员批准 | X | X | X | X | | | | |
| 需要实验室主任批准 | X | X | | | | | | |
| 技术员可自行授权 | | | | | X | X | X | X |
| 生成危险品处置表单 | X | X | X | X | | | | |
| 生成标准处置表单 | | | | | X | X | X | X |
| 标记为需监管报告 | X | | X | | | | | |
| 排入常规处置队列 | | X | | X | X | X | X | X |
| 优先处置（立即） | X | | X | | | | | |

## 完整性检查
- 条件数量：3
- 预期规则数：2^3 = 8
- 实际规则数：8
- 缺失规则：无
- 矛盾：无

## 关键观察
- 危险化学品始终需要 EHS 批准和危险品表单（规则 1-4）
- 大量危险品需额外获得实验室主任批准（规则 1-2）
- 过期的危险化学品需标记为监管报告并进行优先处置（规则 1、3）
- 非危险化学品始终允许技术员自行授权（规则 5-8）

## 派生需求
- CT.DISP.1：当化学品为危险品时，系统应在处理处置前要求 EHS 官员批准。
- CT.DISP.2：当化学品为危险品且数量超过 5 kg 时，系统应额外要求实验室主任批准。
- CT.DISP.3：当处置危险化学品时，系统应按 EPA 要求生成危险品处置表单。
- CT.DISP.4：当危险化学品已过期时，系统应将其标记为需监管报告，并分配优先（立即）处置状态。
- CT.DISP.5：当化学品为非危险品时，系统应允许实验室技术员自行授权处置。
```

**为什么这个示例有效：**
- 所有 8 种组合都已涵盖（2^3 = 8）
- 每条规则至少有一个动作
- 复杂的交互关系清晰可见（过期 + 危险 + 大量 = 最高级别审批 + 优先处置）
- 派生需求是具体的、可测试的"应"（shall）陈述

## 示例 2：扩展条目判定表

```markdown
# 判定表：运费计算

**来源：** BR-003（免费运输）、BR-004（危险品附加费）、BR-022（国际运输）

| | 规则 1 | 规则 2 | 规则 3 | 规则 4 | 规则 5 | 规则 6 |
|---|--------|--------|--------|--------|--------|--------|
| **条件** | | | | | | |
| 订单总额 | < $75 | < $75 | >= $75 | >= $75 | >= $75 | < $75 |
| 目的地 | 国内 | 国际 | 国内 | 国际 | 国内 | 国际 |
| 包含危险品？ | -- | -- | N | N | Y | -- |
| **动作** | | | | | | |
| 标准运费（$5） | X | | | | | |
| 国际运费（$15） | | X | | | | X |
| 免费运输 | | | X | | | |
| 免费国内运费 + 国际附加费 | | | | X | | |
| 危险品附加费（$25） | | | | | X | |
| 运费总计公式 | $5 | $15 | $0 | $15 | $25 | $15 |

注意：规则 1-2 和 6 对危险品使用"--"，因为订单总额低于 $75，
无论如何都需收取运费。付费运费基础上的危险品附加费由规则 1/2/6 + $25

```

**此示例暴露了一个遗漏：** 对于总额 < $75 且包含危险品的订单该怎么处理？当前表格未涵盖该场景。这正是判定表旨在揭示的那类缺失需求。
