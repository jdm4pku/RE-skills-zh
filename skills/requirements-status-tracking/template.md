# 需求状态跟踪仪表盘模板

使用此模板维护需求状态跟踪仪表盘，包含状态分布和指标。

## 模板

```markdown
# 需求状态仪表盘：[项目名称]

**报告日期：** [YYYY-MM-DD]
**版本发布：** [版本标识]
**基线版本：** [版本 X.Y]
**报告周期：** [Sprint X / 第 X 周]

## 状态分布

| 状态 | 数量 | 百分比 |
|--------|-------|---|
| 已提议 | [N] | [%] |
| 进行中 | [N] | [%] |
| 已草拟 | [N] | [%] |
| 已批准 | [N] | [%] |
| 已实现 | [N] | [%] |
| 已验证 | [N] | [%] |
| 已延期 | [N] | [%] |
| 已删除 | [N] | [%] |
| 已拒绝 | [N] | [%] |
| **总计** | **[N]** | **100%** |

## 进度指标

| 指标 | 值 | 趋势 | 目标 |
|--------|-------|-------|--------|
| 规格完成度 | [%] | [上升/下降/稳定] | [%] |
| 实现进度 | [%] | [上升/下降/稳定] | [%] |
| 验证进度 | [%] | [上升/下降/稳定] | [%] |
| 变更率 | [%] | [上升/下降/稳定] | < [X]% |
| 阻塞项 | [N] | [上升/下降/稳定] | 0 |

## 瓶颈分析

| 瓶颈 | 证据 | 建议措施 |
|-----------|----------|-------------------|
| [状态堆积处] | [N 个条目停滞 X 个迭代] | [措施] |

## 停滞需求（2 个以上迭代无变化）

| 需求 ID | 当前状态 | 停滞迭代数 | 所需措施 |
|--------|---------------|---------------|---------------|
| [ID] | [状态] | [N] | [措施] |

## 评估
**总体状态：** [正常 / 有风险 / 落后]
**总结：** [1-2 句评估]
**关键行动：**
1. [行动，包含负责人和日期]
```

## 注意事项
- 至少每个迭代或报告周期更新一次。
- 停滞需求（2 个以上迭代无状态转换）应逐个调查。
- 保持终态（已延期、已删除、已拒绝）可见，以确保完整性。
