# 需求基线记录模板

使用此模板记录正式的需求基线，包括版本控制和审批记录。

## 模板

```markdown
# 需求基线记录

## 基线标识

| 属性 | 值 |
|------|-----|
| **基线 ID：** | [BL-XXX-NNN] |
| **版本标签：** | [Version X.Y approved] |
| **建立日期：** | [YYYY-MM-DD] |
| **上一个基线：** | [ID 或"无（初始基线）"] |
| **项目：** | [项目名称] |
| **发布：** | [发布标识符] |

## 包含的文档

| 文档 | 版本 | 位置 |
|------|------|------|
| [文档名称] | [X.Y] | [路径或 URL] |

## 准入标准验证

| 标准 | 状态 | 证据 |
|------|------|------|
| 正式评审已完成 | [通过/未通过] | [评审 ID] |
| 评审行动项已解决 | [通过/未通过] | [X/Y 已关闭] |
| TBD 项已解决或推迟 | [通过/未通过] | [数量] |
| 需求已唯一标识 | [通过/未通过] | [ID 范围] |
| 优先级已分配 | [通过/未通过] | [方法] |
| 所有需求可测试 | [通过/未通过] | [方法] |
| 可追溯性已建立 | [通过/未通过] | [位置] |
| 干系人签署已获得 | [通过/未通过] | [数量] |
| 无未关闭的高严重性缺陷 | [通过/未通过] | [数量] |

**结果：** [可以建立基线 / 尚未就绪]

## 基线内容摘要

| 类别 | 数量 | ID 范围 |
|------|------|---------|
| 功能需求 | [N] | [FR-XX 至 FR-YY] |
| 非功能需求 | [N] | [NFR-XX 至 NFR-YY] |
| **合计** | **[N]** | |

## 审批

| 角色 | 姓名 | 日期 | 决定 |
|------|------|------|------|
| 产品负责人 | [姓名] | [日期] | [已批准 / 有条件批准] |
| 技术负责人 | [姓名] | [日期] | [已批准 / 有条件批准] |
| 项目经理 | [姓名] | [日期] | [已批准 / 有条件批准] |
| QA 负责人 | [姓名] | [日期] | [已批准 / 有条件批准] |

## 已知问题和推迟项

| 项目 | 推迟至 | 理由 |
|------|--------|------|
| [描述] | [发布/迭代] | [推迟原因] |
```

## 注意事项
- 在所有准入标准通过之前不要建立基线。
- 草稿使用"Version X.Y draft Z"，基线使用"Version X.Y approved"。
- 基线后的每项变更都必须通过变更控制流程。
