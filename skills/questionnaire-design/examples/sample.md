# 需求问卷示例

## 示例1：ChemTrack 问卷

```markdown
# 需求问卷：ChemTrack 化学品库存管理系统

**目的：** 验证和排序需求优先级，为第1版本功能选择提供依据。
**目标受众：** 8个化学实验室的全体实验人员（约200名用户）
**预计完成时间：** 8分钟
**截止日期：** 2024-02-28

---

## 第1部分：背景信息

Q1. 您的主要角色是什么？
- [ ] 实验室技术员
- [ ] 研究生/研究人员
- [ ] 实验室主管
- [ ] 安全员

Q2. 您与化学品库存的交互频率？
- [ ] 每天  [ ] 每周几次  [ ] 每周一次  [ ] 每月或更少

## 第2部分：当前流程评估

请评价您的同意程度（1 = 非常不同意 到 5 = 非常同意）：

Q4. 我能在当前库存中轻松找到特定化学品。
Q5. 我确信有效期被准确跟踪。
Q6. 当前接收新化学品的流程是高效的。

## 第3部分：功能优先级排序

Q8. 请排序以下功能（1 = 最重要，5 = 最不重要）：
___ 自动过期日期提醒
___ 按CAS号、名称或位置搜索
___ 移动端数据录入（实验室中使用平板）
___ 重复化学品检测
___ 自动月度合规报告

## 第4部分：偏好选择

Q10. 如果只能选择一项改进，您会选择哪个？
- [ ] 过期提醒（确保没有化学品在无人知晓的情况下过期）
- [ ] 更好的搜索（让我能在几秒内找到任何化学品）

Q11. 系统应在过期前多久发出提醒？
- [ ] 7天  [ ] 14天  [ ] 30天  [ ] 60天

## 第5部分：开放式问题

Q12. 当前流程中最大的问题是什么？
     ____________________________________________________________
```

## 示例2：结果分析

```markdown
# ChemTrack 问卷结果（n=87/200，回复率：43.5%）

## 当前流程评估

| 问题 | 均值 | 中位数 | 分布 |
|------|------|--------|------|
| Q4：能轻松找到化学品 | 2.1 | 2 | 偏向负面 |
| Q5：有效期跟踪准确 | 1.8 | 2 | 强烈负面 |
| Q6：接收流程高效 | 2.5 | 3 | 双峰分布 |

## 功能优先级排序

| 功能 | 加权分数 | 排名 |
|------|---------|------|
| 过期提醒 | 4.3 / 5.0 | 1 |
| 按CAS号搜索 | 3.8 / 5.0 | 2 |
| 移动端数据录入 | 3.2 / 5.0 | 3 |
| 重复检测 | 2.5 / 5.0 | 4 |
| 合规报告 | 1.2 / 5.0 | 5 |

**按角色交叉列表：**
- 实验室技术员将移动端数据录入列为第1位
- 实验室主管将过期提醒列为第1位
- 安全员将合规报告列为第1位

## 偏好选择

Q10 强制选择：过期提醒 62%，更好的搜索 38%
Q11 提醒时间：30天（57%），14天（28%），60天（11%），7天（4%）

## 需求决策

| 决策 | 数据来源 | 结果 |
|------|---------|------|
| 第1版本包含过期提醒 | Q8排名第1，Q10占62% | 确认 |
| 提醒阈值：30天 | Q11：57%选择30天 | 确认 |
| CAS号作为主要搜索方式 | Q9：44%首选标识符 | 确认 |
| 第1版本包含移动端数据录入 | Q8技术员排名第1 | 确认 |
```

**为什么有效：**
- 简短问卷（12个问题，10分钟以内）
- 按角色交叉列表揭示了隐藏的优先级
- 数据与需求决策直接关联
