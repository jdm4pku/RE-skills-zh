# 需求问卷模板

使用此模板为广泛的利益相关者输入设计需求问卷。

## 模板

```markdown
# 需求问卷：[项目名称]

**目的：** [这些数据将为什么决策提供依据？]
**目标受众：** [用户类别、部门]
**预计完成时间：** [X分钟]
**截止日期：** [日期]

---

## 第1部分：背景信息（事实/人口统计）

Q1. 您的角色是什么？
- [ ] [角色A]
- [ ] [角色B]
- [ ] [角色C]
- [ ] 其他：___________

Q2. 您与[当前系统/流程]交互的频率？
- [ ] 每天
- [ ] 每周几次
- [ ] 每周一次
- [ ] 每月或更少

## 第2部分：当前流程评估（Likert量表）

请评价您的同意程度（1 = 非常不同意 到 5 = 非常同意）：

Q3. 当前的[流程]满足我的需求。
    [ 1 ]  [ 2 ]  [ 3 ]  [ 4 ]  [ 5 ]

Q4. 我能轻松找到所需信息。
    [ 1 ]  [ 2 ]  [ 3 ]  [ 4 ]  [ 5 ]

## 第3部分：功能优先级排序（排序题）

Q5. 请按重要性排序以下功能（1 = 最重要）：
___ [功能A]
___ [功能B]
___ [功能C]

## 第4部分：偏好选择（强制选择）

Q6. 如果只能选一个，您会选择哪个？
- [ ] [能力X]
- [ ] [能力Y]

## 第5部分：开放式问题（最多1-2个问题）

Q7. 当前[系统/流程]中最大的问题是什么？
    ____________________________________________________________

---

**感谢您的参与。结果将于[日期]前分享。**
```

## 注意事项
- 总问题数控制在15-20个。每个问题都必须证明其存在的必要性。
- 部署前与3-5人进行试点测试。目标在10分钟以内完成。
- 始终包含一个强制选择题以揭示真正的优先级。
