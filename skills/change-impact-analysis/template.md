# 变更影响分析模板

使用此模板在 CCB 决策之前评估提议的需求变更的影响。

## 模板

```markdown
# 变更影响分析

## 变更请求摘要

| 属性 | 值 |
|------|-----|
| **CR ID：** | [CR-XXX] |
| **提交日期：** | [YYYY-MM-DD] |
| **请求者：** | [姓名和角色] |
| **变更类型：** | [增强 / 缺陷 / 约束 / 接口] |
| **优先级：** | [关键 / 高 / 中 / 低] |
| **描述：** | [请求的变更内容] |
| **理由：** | [为什么需要此变更] |

## 影响清单
- [ ] 与现有需求冲突？
- [ ] 影响质量属性？
- [ ] 需要架构变更？
- [ ] 影响外部接口或业务规则？
- [ ] 引入法规义务？
- [ ] 影响用户文档、培训或测试用例？
- [ ] 创建新的依赖关系？

## 受影响的工作产品

| 工作产品 | 具体项 | 变更性质 |
|---------|--------|---------|
| SRS | [需求 ID] | [添加 / 修改 / 删除] |
| 架构 | [组件] | [描述] |
| 测试计划 | [测试用例] | [添加 / 修改 / 删除] |
| 用户手册 | [章节] | [描述] |

## 工作量和进度估算

| 任务 | 估算工作量 |
|------|-----------|
| 需求更新 | [小时] |
| 实施 | [小时] |
| 测试 | [小时] |
| **合计** | **[小时]** |

- **进度影响：** [+X 个冲刺/天] | **成本影响：** [$X 或预算百分比]

## 风险和替代方案

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|---------|
| [描述] | [高/中/低] | [高/中/低] | [策略] |

| 替代方案 | 优点 | 缺点 | 工作量 |
|---------|------|------|--------|
| [按提议方案] | [优点] | [缺点] | [工作量] |
| [什么都不做] | [优点] | [缺点] | 0 |

## 建议和 CCB 决策
**建议：** [批准 / 推迟 / 拒绝]
**理由：** [原因]
**CCB 决策：** [决策] 于 [日期] 由 [姓名]
```

## 注意事项
- 根据变更规模调整分析深度。始终至少包含一个替代方案。
- 工作量估算应包括测试和文档，而不仅仅是编码。
