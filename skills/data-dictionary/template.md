# 数据字典模板

使用此模板记录数据元素、结构和 CRUD 分析。

## 模板

```markdown
# 数据字典：[项目名称]

**版本：** [x.y]
**日期：** [YYYY-MM-DD]

---

## 基本数据元素

### [元素名称]
- **类型：** [字符串 / 整数 / 小数 / 日期 / 布尔 / 枚举]
- **格式：** [模式、长度、精度]
- **有效值：** [范围、枚举或约束]
- **默认值：** [默认值（如有）]
- **示例：** [代表性的值]
- **备注：** [补充说明、数据来源、更新频率]

*（对每个基本类型重复上述内容）*

---

## 数据结构

### [结构名称]
```
[structure_name] = [element1] + [element2] + ([optional_element]) + {repeating_element}
```
- **描述：** [该结构表示什么]
- **使用场景：** [哪些功能、用例或报告引用了该结构]

*（对每个结构重复上述内容）*

---

## 枚举

### [枚举名称]
| 值 | 显示标签 | 描述 |
|-------|--------------|-------------|
| [值] | [标签] | [该值的含义] |

*（对每个枚举重复上述内容）*

---

## CRUD 矩阵

|                     | [实体 1] | [实体 2] | [实体 3] |
|---------------------|-----------|-----------|-----------|
| [功能/用例 1]     | C/R/U/D   |           |           |
| [功能/用例 2]     |           | C/R/U/D   |           |

### CRUD 分析发现
- [缺少操作的实体及说明]
- [没有数据访问的功能及说明]
```

## 说明
- 表示法：`=`（由……组成）、`+`（与）、`[a|b]`（选择）、`{x}`（重复）、`(x)`（可选）
- 需求中使用的每个数据术语都必须在此处有对应条目。
- 检查 CRUD 矩阵中的空行（未使用的功能）和空列（未管理的实体）。
