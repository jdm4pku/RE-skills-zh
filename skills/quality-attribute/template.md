# 质量属性规格说明模板

使用此模板通过 Planguage 标记法指定质量属性。

## 模板

```markdown
# 质量属性规格说明：[项目名称]

**版本：** [x.y]
**日期：** [YYYY-MM-DD]

---

## 质量属性权衡矩阵

|              | [属性 1] | [属性 2] | [属性 3] | [属性 4] |
|--------------|----------|----------|----------|----------|
| [属性 1]     | --       | [胜出者] | [胜出者] | [胜出者] |
| [属性 2]     |          | --       | [胜出者] | [胜出者] |
| [属性 3]     |          |          | --       | [胜出者] |
| [属性 4]     |          |          |          | --       |

**优先级顺序：** [排序列表]
**理由：** [为何如此排序]

---

## 质量属性规格说明

### [QA-ID]：[属性名称]

- **Tag:** [被度量的具体方面]
- **Ambition:** [定性目标描述]
- **Scale:** [度量单位]
- **Meter:** [如何度量 -- 测试方法、工具、条件]
- **Past:** [当前基线度量值]
- **Fail:** [不可接受的阈值 -- 超过则系统无法满足需求]
- **Goal:** [现实可行的目标]
- **Stretch:** [理想目标，超越 Goal]
- **Wish:** [期望值，不承诺]
- **Source:** [谁指定的，基于什么证据]
- **Priority:** [高 / 中 / 低]
- **Traces to:** [业务目标 ID]
- **Constraints:** [限制可达成目标的因素]

*（为每个质量属性重复以上内容）*

---

## 约束条件

### [CONST-ID]：[约束名称]
- **类型：** [技术 / 平台 / 标准 / 法规 / 物理]
- **描述：** [什么被约束以及如何约束]
- **来源：** [约束的来源]
- **影响：** [影响哪些质量属性或功能]
```

## 注意事项
- 每个质量属性必须至少包含 Scale、Meter、Goal 和 Fail。
- 权衡矩阵强制进行明确的冲突解决 -- 不要跳过它。
- Past（基线）值有助于证明改进目标的投资合理性。
- 约束条件是不可协商的 -- 它们界定了解决方案的空间。
