# 质量属性示例

## 示例：ChemTrack 质量属性

```markdown
# 质量属性规格说明：ChemTrack

**版本：** 1.0
**日期：** 2025-04-01

---

## 质量属性权衡矩阵

|              | 性能 | 安全性 | 易用性 | 可用性 |
|--------------|-------------|----------|-----------|-------------|
| 性能  | --          | 安全性胜出 | 性能胜出 | 可用性胜出  |
| 安全性     | 安全性胜出    | --       | 安全性胜出  | 安全性胜出    |
| 易用性    | 性能胜出   | 安全性胜出 | --        | 可用性胜出  |
| 可用性 | 可用性胜出  | 安全性胜出 | 可用性胜出| --          |

**优先级顺序：** 安全性 > 可用性 > 性能 > 易用性
**理由：** 化学品安全数据必须安全（法规强制要求）。
系统在实验室开放时间必须可用（安全影响）。速度对
日常实验室操作很重要。易用性是期望的但属于次要的。

---

## 质量属性规格说明

### QA-001：搜索响应时间

- **Tag:** 响应时间（搜索操作）
- **Ambition:** 搜索结果显示足够快，实验室技术人员
  在工作台操作时不会打断思路
- **Scale:** 从提交搜索查询到完整结果显示的秒数
- **Meter:** 50 个并发用户对 50,000 条化学品记录数据库的
  自动化负载测试；在第 95 百分位处测量
- **Past:** 4.2 秒（当前使用 VLOOKUP 的电子表格查找）
- **Fail:** > 5 秒（技术人员恢复手动货架扫描）
- **Goal:** <= 2 秒
- **Stretch:** <= 1 秒
- **Wish:** <= 0.5 秒（即时响应感知）
- **Source:** 实验室技术人员用户类（Maria Santos），可用性研讨会
- **Priority:** 高
- **Traces to:** BO-1（减少报告时间）
- **Constraints:** 大学网络带宽（100 Mbps 校园局域网）

### QA-002：系统可用性

- **Tag:** 运行可用性
- **Ambition:** 系统在实验室开放运行期间随时可用
- **Scale:** 计划运行时间内系统可访问的百分比
- **Meter:** 在计划时间内（周一至周五 7:00-22:00，周六 8:00-17:00）
  每 60 秒检查一次的运行时间监控工具（如 Pingdom）
- **Past:** 不适用（新系统；电子表格没有"运行时间"）
- **Fail:** < 95%（每周超过 4.5 小时停机时间）
- **Goal:** >= 99.5%（每周最多 30 分钟停机时间）
- **Stretch:** >= 99.9%（每周最多 5 分钟停机时间）
- **Source:** EHS 合规官（Tom Rivera）
- **Priority:** 高
- **Traces to:** BO-4（减少安全事故）
- **Constraints:** IT 部门提供共享主机；目前没有
  专用基础设施预算

### QA-003：审计追踪完整性

- **Tag:** 数据完整性（审计日志）
- **Ambition:** 每次数据修改都被永久且防篡改地
  记录，以符合法规要求
- **Scale:** 审计日志中捕获的数据修改事件百分比，
  包含完整的修改前/修改后值
- **Meter:** 季度审计：将 100 个修改事件的随机样本
  与审计日志条目进行比较；验证完整性和不可篡改性
- **Past:** 不适用（当前没有审计追踪）
- **Fail:** < 100%（任何遗漏事件都是合规违规）
- **Goal:** 100% 捕获率，具有防篡改存储
- **Source:** EHS 合规官（Tom Rivera），DEA 21 CFR 1304
- **Priority:** 关键（法规要求）
- **Traces to:** BO-4（减少安全事故）

---

## 约束条件

### CONST-001：大学 SSO 强制要求
- **类型：** 技术
- **描述：** 所有 Web 应用程序必须通过大学的
  Active Directory SSO 进行身份验证。不允许本地用户账户。
- **来源：** IT 安全策略（2024-07）
- **影响：** 影响 QA-003（审计追踪必须捕获 AD 用户 ID），
  排除自助注册功能选项

### CONST-002：WCAG 2.1 合规
- **类型：** 标准
- **描述：** 所有用户界面必须符合 WCAG 2.1 AA 级
  无障碍访问指南。
- **来源：** 大学无障碍访问政策（联邦 Section 508）
- **影响：** 影响易用性属性规格说明和 UI 设计
```

**为什么这样有效：**
- 每个属性都包含所有 Planguage 标签（Scale、Meter、Goal、Fail）
- Past 基线值证明了改进目标的合理性
- Fail 阈值清晰地定义了不可接受的性能
- 权衡矩阵使冲突解决透明化
- 约束条件与可协商的质量目标分开记录
- 所有内容都可追溯到业务目标
