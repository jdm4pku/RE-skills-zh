# 访谈指南模板

使用此模板为需求获取访谈做准备。

## 模板

```markdown
# 访谈指南：[项目名称]

**受访者：** [姓名，职务]
**访谈者：** [姓名]
**日期：** [YYYY-MM-DD]
**时长：** [计划时长，例如 60 分钟]
**目标：** [您需要从此次访谈中获取什么具体知识？]

---

## 访谈前准备
- [ ] 已查阅现有文档：[列出已查阅的文档]
- [ ] 已确认干系人的用户类别：[用户类别]
- [ ] 已与干系人分享议程

## 上下文无关问题（10 分钟）
1. 您能描述一下您的角色以及您如何与[系统/流程]互动吗？
2. 当前[流程/系统]中最大的问题是什么？
3. 成功的解决方案在您看来是什么样的？
4. 有什么约束条件或法规要求是我应该了解的吗？

## 上下文相关问题（30-40 分钟）

### 主题：[主题 1，例如"化学品入库流程"]
5. 请您描述一下当[某个具体事件]发生时的处理流程。
6. 在那个环节您需要记录什么信息？
7. 当[异常或错误情况]发生时会怎样？
8. 请告诉我上一次[某个具体问题]发生时的情况。

### 主题：[主题 2，例如"报告与合规"]
9. [关于此主题领域的问题]
10. [关于过去行为的追问]

## 元问题（5-10 分钟）
11. 有什么我应该问但没问到的吗？
12. 关于这个话题，我还应该跟谁谈谈？
13. 有哪些文档或资料是我应该查阅的？

---

## 访谈记录

| 时间 | 主题 | 记录 | 标签 |
|------|------|------|------|
| | | | [PAIN/WORKAROUND/FREQ/IMPACT/WISH] |

## 后续行动
- [ ] 在[日期]前将摘要发送给干系人
- [ ] 安排后续访谈讨论[待解决问题]
- [ ] 访谈[受访者提到的其他干系人]

## 提取的候选需求
| 需求 ID | 需求描述 | 来源 | 优先级 |
|---------|---------|------|--------|
| | | 本次访谈 | |
```

## 注意事项
- 准备 10-15 个问题，但要跟随有价值的线索深入探讨。
- 始终在 48 小时内发送摘要供干系人验证。
- 在访谈过程中为笔记打标签，以便后续更快地提取需求。
