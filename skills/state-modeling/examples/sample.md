# 状态建模示例

## 示例：化学品记录生命周期

```markdown
# 状态模型：化学品记录

**日期：** 2025-04-01
**作者：** Sarah Chen

---

## 状态

| 状态 | 描述 | 进入条件 | 终止状态？ |
|------|------|---------|-----------|
| 活跃（Active） | 化学品在库存中且可安全使用 | 由技术员添加，CAS 编号已验证 | 否 |
| 即将过期（Expiring Soon） | 化学品即将到达过期日期 | 距过期日期 30 天 | 否 |
| 已过期（Expired） | 化学品已超过过期日期，不安全 | 过期日期已过 | 否 |
| 已处置（Disposed） | 化学品已被物理移除并记录 | 技术员记录处置 | 是 |
| 已转移（Transferred） | 化学品已转移到其他机构 | 转移审批完成 | 是 |

## 事件

| 事件 | 描述 | 来源 |
|------|------|------|
| add_chemical | 提交并验证新的化学品条目 | 实验室技术员 |
| thirty_day_mark | 日历日期到达过期前 30 天 | 系统（定时器） |
| expiration_passed | 日历日期超过化学品的过期日期 | 系统（定时器） |
| dispose | 技术员记录化学品的物理处置 | 实验室技术员 |
| transfer | 化学品转移到其他机构 | 实验室主任 |
| renew | 化学品的过期日期被延长（重新认证） | 实验室技术员 |
| update_quantity | 使用量或添加量更新 | 实验室技术员 |
| generate_report | 请求合规报告 | EHS 官员 |

## 状态表

| 状态 \ 事件 | add_chemical | thirty_day_mark | expiration_passed | dispose | transfer | renew | update_quantity | generate_report |
|------------|-------------|----------------|-------------------|---------|----------|-------|----------------|----------------|
| 活跃 | 错误：重复 | -> 即将过期 / 发送预警邮件 | -> 已过期 / 发送紧急预警，禁止使用 | -> 已处置 / 记录处置，更新库存 | -> 已转移 / 记录转移，通知 EHS | 错误：未临近过期 | 更新数量 / 记录变更 | 纳入报告 / 只读 |
| 即将过期 | 错误：重复 | --（已通知） | -> 已过期 / 发送紧急预警，禁止使用 | -> 已处置 / 记录处置，更新库存 | -> 已转移 / 记录转移，通知 EHS | -> 活跃 / 更新过期日期，清除预警 | 更新数量 / 记录变更 | 纳入报告并标记警告 |
| 已过期 | 错误：重复 | --（已过期） | --（已经过期） | -> 已处置 / 记录处置，更新库存 | 错误：不能转移已过期化学品 | 错误：必须处置已过期化学品 | 错误：不能使用已过期化学品 | 纳入报告并标记违规 |
| 已处置 | 错误 | 错误 | 错误 | 错误：已处置 | 错误：已处置 | 错误：已处置 | 错误：已处置 | 纳入报告标记为已处置 |
| 已转移 | 错误 | 错误 | 错误 | 错误：不在库存中 | 错误：已转移 | 错误：不在库存中 | 错误：不在库存中 | 纳入报告标记为已转移 |

## 导出的需求

| 需求 ID | 状态 | 事件 | 需求 |
|---------|------|------|------|
| CT.STATE.1 | 活跃 | thirty_day_mark | 当化学品处于活跃状态且距过期 30 天时，系统应将其状态变更为即将过期，并向指定技术员发送预警邮件 |
| CT.STATE.2 | 活跃 | expiration_passed | 当化学品处于活跃状态且过期日期已过时，系统应将其状态变更为已过期，发送紧急预警，并禁止将该化学品分配给实验 |
| CT.STATE.3 | 即将过期 | renew | 当即将过期的化学品被重新认证时，系统应更新其过期日期，将状态变更为活跃，并清除待处理的预警 |
| CT.STATE.4 | 已过期 | renew | 如果技术员尝试续期已过期的化学品，系统应拒绝该操作并显示"已过期的化学品必须处置，不允许续期。" |
| CT.STATE.5 | 已过期 | update_quantity | 如果技术员尝试使用已过期的化学品，系统应拒绝该操作并显示"不能使用已过期的化学品，请处置并订购替代品。" |
| CT.STATE.6 | 任意 | dispose | 当处于任何非终止状态的化学品被处置时，系统应记录处置信息（包括技术员 ID、时间戳和处置方式），更新库存数量，并将状态设置为已处置 |
```

**为何有效：**
- 状态表中每个单元格都已填写（无遗漏需求）
- 错误条件明确，有具体的错误消息
- 终止状态（已处置、已转移）没有有效的出向转换
- 导出的需求以可测试的"应"格式编写
- 该模型暴露了"已过期的化学品不能续期"等规则，这些规则在用例分析中可能不会浮现
