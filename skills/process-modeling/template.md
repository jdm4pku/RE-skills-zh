# 流程模型规格说明模板

使用此模板记录流程模型及其图表、参与者和推导的需求。

## 模板

```markdown
# 流程模型：[流程名称]

**流程 ID：** [PM-001]
**状态：** [草稿 / 已审查 / 已批准]
**作者：** [姓名]
**日期：** [YYYY-MM-DD]

---

## 流程概述
[一段话描述此流程完成的工作。]

## 参与者（泳道）

| 泳道 | 参与者 / 角色 | 职责 |
|------|-------------|------|
| 1 | [角色 A] | [此参与者在此流程中做什么] |
| 2 | [系统名称] | [自动化操作] |
| 3 | [角色 B] | [此参与者做什么] |

## 触发条件
[什么事件启动此流程？]

## 前置条件
- [此流程开始前必须满足的条件]

## 流程流转

| 步骤 | 泳道 | 动作 | 输出 |
|------|------|------|------|
| 1 | [参与者] | [动作描述] | [结果] |
| D1 | [参与者] | 决策：[条件？] | 是 --> 步骤 X，否 --> 步骤 Y |
| F1 | -- | 分支：并行路径开始 | |
| 2a | [参与者] | [并行动作 A] | |
| 2b | [参与者] | [并行动作 B] | |
| J1 | -- | 汇合：并行路径合并 | |

## 交接

| 从 | 到 | 交接内容 | 在步骤 |
|----|----|---------|--------|
| [参与者 A] | [系统] | [数据或工件] | 步骤 N |

## 推导的需求

| 需求 ID | 需求陈述 | 来源（图表元素） |
|---------|---------|----------------|
| | [从动作推导的需求] | 步骤 N |
| | [从决策推导的需求] | 决策 D1 |
| | [从交接推导的需求] | 步骤 M 的交接 |

## 后置条件
- [此流程成功完成后为真的条件]
## 验证
- [ ] 已与 [角色 A] 审查
- [ ] 已与 [角色 B] 审查
- [ ] 所有决策分支都有明确的结果
- [ ] 所有交接都有推导的需求
```

## 注意事项
- 将每张图限制在 7-15 个动作。将大型流程拆分为子流程。
- 每个交接都是通知或数据传输需求的候选项。
