# 上下文图模板

使用此模板创建系统上下文图。

## 模板

```markdown
# 上下文图：[系统名称]

**日期：** [YYYY-MM-DD]
**作者：** [姓名]

---

## 系统
[系统名称] -- [一句话描述系统的功能]

## 外部实体

| 实体 | 类型 | 描述 |
|------|------|------|
| [名称] | 用户 / 外部系统 / 设备 / 组织 | [它是什么] |

## 数据流

| 来源 | 目标 | 数据流名称 | 描述 |
|------|------|-----------|------|
| [实体/系统] | [系统/实体] | [flow_name] | [交换了什么数据] |

## 图示（文本表示）

```
[实体 A] --data_flow_1--> (系统) --data_flow_2--> [实体 B]
[实体 C] --data_flow_3--> (系统)
(系统) --data_flow_4--> [实体 D]
```

## 导出的需求

| 数据流 | 输入/输出 | 需要定义的需求 |
|--------|----------|--------------|
| [flow_name] | 输入 | 格式、验证规则、频率 |
| [flow_name] | 输出 | 内容、格式、触发条件、时效 |
```

## 注意事项
- 系统必须是单个气泡——不要分解。
- 每个外部实体必须至少有一个数据流。
- 每个数据流必须有描述性名称（名词短语，不是"数据"）。
- 外部实体之间没有数据流。
