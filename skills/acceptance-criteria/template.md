# 验收标准模板

使用此模板为需求编写验收标准。

## 模板

```markdown
# 验收标准：[需求 ID / 故事 ID]

**需求：** [完整的需求声明]
**格式：** [Given/When/Then | 检查清单 | 基于规则]

---

## Given/When/Then 格式

**[AC-ID]:**
Given [前置条件],
and [附加前置条件],
When [动作或触发器],
Then [预期结果].

## 检查清单格式

- [ ] [可测试条件 1]
- [ ] [可测试条件 2]
- [ ] [负面条件 -- 什么不应该发生]

## 基于规则格式

**Rule:** [业务规则声明]
- Example: [输入场景] -> [预期输出]
- Example: [边界场景] -> [预期输出]
- Example: [错误场景] -> [预期输出]

---

## 验证检查清单
- [ ] 每个标准测试一个具体条件
- [ ] 已覆盖边界条件
- [ ] 至少包含一个负面测试用例
- [ ] 测试人员无需询问澄清即可判定通过/失败
- [ ] 标准可追溯到父需求
```

## 备注
- 每个需求选择一种格式（不要在单个需求内混用格式）。
- 每个需求 3-7 个标准是目标范围。
- 始终包含至少一个负面用例（什么不应该发生）。
