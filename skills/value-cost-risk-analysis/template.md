# 价值/成本/风险分析模板

**作者：** [姓名]

**权重：** 收益 = [2]，惩罚 = [1]，成本 = [1]，风险 = [0.5]

---

## 说明
- 评分锚定标准：1=极小，3=低，5=中等，7=高，9=关键。
- 在计算之前，通过讨论解决异常值（相差 4 分以上）。
- 始终记录人工调整及其理由。
