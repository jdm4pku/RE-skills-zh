# 在聊天工具中使用 RE Skills（Claude Desktop、ChatGPT 等）

## 准备工作

无需安装任何工具。将技能文件直接上传到聊天对话中即可使用。

## 使用步骤

1. **选择技能** — 从 `LIST.md` 中根据需求找到对应的技能
2. **上传 SKILL.md 文件** — 将技能文件上传到聊天窗口
3. **提供项目背景**，要求 AI 按照技能指引执行：

```text
请使用上传的 RE 技能作为框架。
先问我最多 3 个澄清问题。
然后以 Markdown 格式输出成果。
最后列出假设、遗漏和下一步建议。
```

## 示例：创建愿景与范围文档

1. 上传 `skills/vision-and-scope/SKILL.md`
2. 输入提示：

```text
我正在为一个大学实验室化学试剂管理系统（ChemTrack）编写愿景与范围文档。请使用上传的技能，先问我澄清问题，然后生成文档。
```

## 示例：获取需求获取技术推荐

1. 上传 `skills/elicitation-technique-selector/SKILL.md`
2. 输入提示：

```text
我有 5 个干系人群体（实验室管理员、EHS 办公室、系主任、IT 部门、研究人员），有 3 周的获取时间，需要同时覆盖功能需求和非功能需求。请推荐合适的需求获取技术。
```

## 使用技巧

- 每次上传 **一个技能文件**，效果最佳
- 对于组件类技能，同时上传 `template.md`，让 AI 按正确结构输出
- 上传 `examples/sample.md` 作为质量参考标准
- 提供真实的项目背景（项目名称、干系人、约束条件），而不是泛泛的描述
- 对于多技能工作流，上传 `commands/命令名.md`，让 AI 按工作流步骤执行
